# 京都ボス「狐火六路陣」実装判断

正本: `docs/Codex実装指示書：京都ボス「狐火六路陣」v1.0.md`

## 今回の製品スライス

仕様書 §36 / §41 を基準に、Slice 1〜9 を同じController/View契約へ段階的に
統合した。Lv1を「狐火のないチュートリアル」ではなく、読み合いを含む
「易しい本番」へ改訂し、Lv1〜8を同じルールの段階的な圧力として扱う。

- 6×6固定盤、4鳥居、1マスずつの経路入力、正確なN歩移動。
- 既存 `V06RollSet` を使う3ROLL SLOTとPAIR/STRAIGHT/TRIPLE判定。役成立時は
  非モーダルカードで結果を見せ、通常マップと共通の旅スキルゲージへ
  PAIR +1／STRAIGHT +2／TRIPLE MAXとして反映する。
- 朱色の active edge、金色の sealed edge、3封印の即時勝利。
- Lv1からの初期白狐火、配置1ターン前の予告、通行不可、完全封鎖による敗北。
- 御朱印4種＋満願札の1戦1回効果（伏見／八坂／清水／天龍寺／満願）。
  使用できる御朱印は「寺社名｜できること」を効果対象の近くに表示する。
  発動時は専用アイコン、効果名、実際の結果を共通カードで通知し、伏見・八坂の
  開始時効果も同じ表現へ揃える。カードは盤面入力を止めず、ルール説明中は
  閉じた後に順番に再生する。
- LAPごとに30%から最大85%まで鋭くなるスコアAI、Lv5の前ターン線切断予告、
  Lv6以降の二択狐火。二択の実配置先もロール前に内部確定し、後出ししない。
- Lv7で桜（狐火浄化）、Lv8で竹林（進入方向の強制直進）を段階解放。
- 勝利時は探検猫を描いた生成キーアート
  `assets/art/bosses/kyoto/fox-fire-victory-key-art-explorer-cat.png` を結果カード上部に
  表示し、白狐の敬礼と完成した三結界を報酬として見せる。
- 初回説明はページ別生成イラスト（移動／ぴったり停止／狐火／御朱印）を使い、
  実プレイ中の探検猫と同じキャラクターでルールを先に視覚化する。御朱印は
  絵文字ではなく `assets/art/ui/kyoto-goshuin-icons.png` の専用アイコンを使う。
- オプションの街区封印ボーナス。閉ループ検出時に狐火を1つ浄化し、次の
  白狐行動をスキップする。既定値は仕様書どおりOFF。

## 曖昧点の初期決定

- A `(2,5)`、B `(3,0)`、C `(0,1)`、D `(5,3)` を固定初期配置とする。
- 鳥居Aは開始時点で訪問済み。伏見稲荷で開始鳥居を変えた場合は、選択した
  鳥居だけを訪問済みにしてそこから3本を結ぶ。
- Lv1〜2は偶数ターン（2、4、6…）に白狐火を置き、TURN 1から次の確定予告を
  表示する。Lv3はTURN 3から毎ターン、Lv4はTURN 2から、Lv5以降はTURN 1から。
- 開始時白狐火はLv1〜2が1個、Lv3〜5が2個、Lv6〜8が3個。Lv1〜3では、
  1手で全未訪問鳥居を完全封鎖する候補を除外する。
- 狐火候補は短い未訪問鳥居ルート、交差点、猫の2〜3歩先、active edge近傍を
  加点し、猫の隣を減点する。賢い候補を使わない回は安全候補からランダム選択。
- 朱色／金色経路は辺。白狐火候補からは、その時点で経路辺に接するセルを
  除外する。
- 封印成立時は現在鳥居から到着鳥居へ接続している active edge の連結成分を
  金色へ移す。active edge は次の封印開始前にクリアする。
- 正確N歩の経路が存在しない場合だけ `MISS` 操作を表示し、白狐行動へ進む。
- 白狐火を置ける合法セルがない場合、その白狐行動は何も置かず終了する。
- 線切断された辺は`severed_edges`へ記録し、プレイヤーが後で同じ辺を
  通過すると自動修復する。
- 敗北BFSでは通常床、鳥居、将来有効化する特殊マスを通行可能として扱い、
  白狐火だけを障害物とする。
- 対応画面は既存製品基準の portrait 720×1280。360×640相当の縮小表示でも
  タップ領域と主要コピーが重ならないことをQAする。

## 境界

- 戦闘ControllerだけがBattle Stateを変更する。Viewは入力Signalを送る。
- ボス戦内部はHP/LIFEを変更しない。敗北結果を既存Journey/GameSession境界へ
  返し、既存のHP減少・LIFE復活処理に任せる。
- 3本目の封印後は白狐行動を一切実行せず、その場でVICTORY結果を返す。
- Snapshotには盤面状態、slot faces、difficulty、battle RNG stateを保存する。
- Snapshotには狐火予告の発生ターン、二択の内部確定先、次回行動ターン、
  線切断予告、切断回数、特殊解決中の選択、切断済み辺、街区ボーナス待ちも保存。

  通常マップと同じ旅スキルゲージへ加算されることを検証。
