# DICE SLOT TRIP Kyoto Chase Core Repair

## Objective

京都通常ステージと「狐火追陣」を、カイロと同じサイコロ・COIN・SKILL・MISSION文法へ揃え、初見操作と敗北後の再出発を安定させる。

## Acceptance

- 狐火追陣は1タップで回転開始し、STOP時の3D上面・SLOT・ゲーム出目が一致する。
- 敗北はその周の敗北としてLAP+1し、通常ステージ先頭へ戻り、COIN・ITEM・SKILLがリセットされる。
- 京都のCOINボタンからカイロと同じ5商品を購入でき、通常／ボス効果が一度だけ発動する。
- SKILLはHP満タンREST停止だけで+1され、SLOT役では増えない。
- 自動達成型MISSIONを抽選しない。
- 狐火追陣Lv1は白狐8マス先行で開始する。
