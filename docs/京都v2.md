\### 共通判定ルール



通常のCOIN / REST / RISK / ITEM / EVENTは\*\*着地時のみ発動\*\*。御朱印だけは例外で、\*\*通過または着地で取得\*\*する。取得演出は移動終了後に短く表示し、移動途中でモーダルを挟まない。



分岐32・71は到達した時点で1回だけ選択し、\*\*残り歩数を保持したまま選択したルートへ進む\*\*。分岐によってターンを追加消費しない。

\## 分岐処理で一つだけ重要



32・71・87はすべて、



\*\*「分岐点へぴったり止まらないと選べない」にはしない。\*\*



たとえば30から6を出した場合、



`30 → 31 → 32`



まで来たところで分岐を表示し、残り4歩を保持。



近道を選べば、



`K1-1 → K1-2 → K1-3 → K1-4`



まで進む。



これなら分岐を飛び越してしまわないし、\*\*分岐のために1ターン浪費もしない\*\*。



御朱印も同様に、通過時に取得フラグだけ立てて移動を続ける。

という\*\*ゲームとして意味のある判断はむしろ濃く残っている\*\*。
