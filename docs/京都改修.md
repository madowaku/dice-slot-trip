京都改修
カイロで**DICE SLOT TRIPの共通文法**がかなり固まったので、京都では新しく発明するより、まずそれを移植して「京都だけの面白さ」を上に載せるのがよさそう。

## 京都改修はこの5段階で進めたい

### Phase 1：まず画面を「カイロ基準」に戻す

最優先。

通常画面は、

* 上部HUDはカイロ準拠
* MISSIONは1周1本
* 中央は**現在地〜+6マスだけ**
* 常設の縦長全体マップは撤去
* 全体マップは `[全体マップ]` ボタンから開く
* SLOTリーチ表示もカイロ準拠
* ITEM / COIN / SKILL / MENUもカイロ準拠
* マスアイコンもカイロ準拠
* 京都独自情報は必要最小限

にする。

つまり、

> **京都をカイロのUIスキン違いに近づける**

くらい大胆でいい。

京都の鳥居背景や色、御朱印などは残すけど、**操作の場所や情報階層は変えない**。

これだけで「どこ見ればいいの？」問題はかなり消えるはず。

---

### Phase 2：90マス構造を「止められない京都」にする


今は、

**分岐 → 選択**
**EVENT → 選択**
**分岐 → 選択**

で旅の勢いが切れている。

なので京都v2では、

#### 分岐

**1周2〜3回まで**

に絞りたい。

しかも分岐するたびに選択画面を出すのではなく、

> 本線
> 近道
> 御朱印ルート

など、**意味のある大きな選択だけ**残す。

#### EVENT

かなり減らしていい。

選択式EVENTは全体の2〜3割程度。

残りは、

* 茶屋で一休み → HP+1
* 狐に化かされた → 2マス戻る
* お守りを拾った → ITEM獲得
* 小銭を見つけた → COIN+2

みたいな**着地→即解決**型へ。

京都のテンポを、

**ROLL → 移動 → チャリン！ → ROLL**

まで戻したい。

---

# Phase 3：カイロで完成した共通システムを全部持ってくる

ここは京都専用に再設計しない。

### MISSION

カイロと同じ、

**1周1MISSION**

をそのまま導入。

ただし京都用MISSION候補も追加できる。

たとえば、

* 御朱印を3個集める
* RISKを5回踏む
* ITEMを3個入手
* STRAIGHTを4回
* 指定目を10回
* 近道を2回使う

など。

つまりMISSIONエンジンは共通、**お題だけ京都対応**。

---

### SLOT

これもカイロそのまま。

PAIR → COIN
STRAIGHT → 多めのCOIN
TRIPLE → 大量COIN

＋

**「次は4でSTRAIGHT！」**

のリーチ表示。

京都に入った途端SLOTルールが変わることはしない。

---

### SKILL

HP満タンREST → SKILLチャージ。

これも共通。

---

# Phase 4：京都のCOIN・ITEMを復活させる


ここは京都を独自経済にしない方がいい。

## COIN

通常マップの用途はカイロと共通。

* RISKガード
* REST強化
* ITEM購入
* ボス準備

など。

見た目だけ京都風にする。

例えば、

**RISKガード**
→ 厄除け守

**REST強化**
→ 薬湯

みたいな味付けはあり。

でも効果は共通。

「カイロで覚えたことが京都でも使える」が大事。

---

## ITEM

京都はITEMマスを増やしたい。

90マスなら、体感的には

**8〜12個程度**

くらいから試したい。

全部踏めるわけではないので、盤面上にそれなりに見えていた方が、

> 「+4に宝箱ある！4狙おう」

が起きる。

共通ITEM3種＋京都専用1〜2種くらいで十分。

---

# Phase 5：最後に京都ボスを別プロジェクトとして作り直す

---


**見た瞬間に次の行動が分かる。**

京都らしさは背景、マス、EVENT、御朱印、ボスで出す。

操作そのものはカイロと同じ。

---

## Sol＋Lunaでやるなら最初のタスク


**Sol**
→ 京都v2全体の統合担当。

**Luna A**
→ 京都UIとカイロUIの差分監査。

**Luna B**
→ 京都90マスの分岐・EVENT頻度監査。

**Luna C**
→ ITEM / COIN / REST / RISKの配置密度監査。

**Luna D**
→ 京都固有要素で「残すもの / 共通化するもの」の分類。
